## 主要実装項目

### PrStatus / PrInfo 型定義 🔵

**信頼性**: 🔵 *architecture.md データモデルより*

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum PrStatus { CiError, Approved, Draft, Ready }

#[derive(Debug, Clone)]
pub struct PrInfo {
    pub number: u32,
    pub title: String,
    pub url: String,
    pub status: PrStatus,
}
```
