`gh pr view` の取得フィールドを拡張し、JSON から `PrStatus` を導く**純粋関数**
`classify_pr_status` を実装する。`fetch_pr_title` を `fetch_pr_info(wt_path) -> Option<PrInfo>`

## 主要実装項目

### classify_pr_status（純粋関数） 🔵

**信頼性**: 🔵 *requirements.md REQ-002 状態判定の詳細・architecture.md より*

判定順序（厳守）:
1. `statusCheckRollup` に失敗系（CheckRun.conclusion ∈ {FAILURE,TIMED_OUT,ACTION_REQUIRED}、
   StatusContext.state ∈ {FAILURE,ERROR}）が1件でもある → `CiError`（pending/running は対象外）
2. `reviewDecision == "APPROVED"` → `Approved`
3. `isDraft == true` → `Draft`
4. その他 → `Ready`

**実装ファイル**: `src/main.rs`

### fetch_pr_info 🔵

**信頼性**: 🔵 *既存 fetch_pr_title (main.rs:5313) の拡張*

- 非同期（`tokio::process::Command`）で `gh pr view --json ...` を実行
- 標準出力を `serde_json` でパース → `classify_pr_status` → `PrInfo { number, title, url, status }`
- 失敗・PR無しは `None`

**実装ファイル**: `src/main.rs`
