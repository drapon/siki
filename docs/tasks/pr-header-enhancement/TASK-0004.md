## タスク概要

`render_branch_header` を更新し、PR 表示を `タイトル #123` 形式（番号後置き）にする。
PR 部分を状態色（CIエラー=Red / approved=Green / draft=DarkGray / ready=Yellow、非フォーカス時は
DarkGray）で描画し、PR 部分の `Rect` を `App.pr_link_area` に記録する（後続のクリック判定で使用）。

- **後続タスク**: [TASK-0005](TASK-0005.md)

## 主要実装項目

### 表示文字列と状態色 🔵

**信頼性**: 🔵 *requirements.md REQ-001/002・architecture.md より*

- `Span` 構成: `[" ", branch(緑/DarkGray), " | ", "タイトル #123"(状態色/DarkGray)]`
- 色変換（`main_panel.rs` 側）: `CiError→Red` / `Approved→Green` / `Draft→DarkGray` / `Ready→Yellow`
- 非フォーカス時は PR 部分を `DarkGray` に（REQ-402）

**実装ファイル**: `src/ui/main_panel.rs`

### クリック領域 Rect の記録 🔵

**信頼性**: 🔵 *architecture.md・既存 unicode_width 利用より*

- PR 部分（`タイトル #123`）の表示開始 x と幅を `unicode_width` で算出し `Rect` を構築
- `render_branch_header` から `Option<Rect>` を返し、借用解消後に `app.pr_link_area` へ代入

**実装ファイル**: `src/ui/main_panel.rs`
