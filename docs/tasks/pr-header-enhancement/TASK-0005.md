## タスク概要

中央ペインヘッダーの PR 部分（`pr_link_area`）を左クリックした際に、該当 PR の URL を
既定ブラウザで開く。OS 別ブラウザ起動ヘルパー `open_in_browser` を新設する。反応範囲は
PR 部分のみとし、ブランチ名部分のクリックでは開かない（REQ-003）。

**実装ファイル**: `src/main.rs`

### open_in_browser ヘルパー 🟡

**信頼性**: 🟡 *requirements.md 非機能「多OS対応」より（本リポジトリは darwin 前提）*

```rust
fn open_in_browser(url: &str) {
    #[cfg(target_os = "macos")] let cmd = "open";
    #[cfg(target_os = "linux")] let cmd = "xdg-open";
    #[cfg(target_os = "windows")] let cmd = "start";
    if std::process::Command::new(cmd).arg(url).spawn().is_err() {
        // show_info 等で通知（UI はブロックしない）
    }
}
```

**実装ファイル**: `src/main.rs`
