## タスク概要

`prompt.rs`（TASK-0006）を `cmd_run` / `cmd_new` / `cmd_rm` に接続し、引数不足時の対話フォールバックを完成させる。
`resolve_project` / `resolve_or_create_worktree` の「不足検知 → prompt → 補完」を実装。
`rm` には削除確認（`confirm`）を入れる。`main.rs` のディスパッチに `new`/`rm`/`path`/`run` を結線し、
`list` を拡張、`--help` を更新。最後に手動 E2E で全コマンドを確認する。
