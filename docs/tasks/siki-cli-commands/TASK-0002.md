## 主要実装項目

### ArgScan::parse 🔵

**信頼性**: 🔵 *dataflow.md「引数パース（ArgScan）」フローより*

- `--` を見たら以降を全て `rest` へ
- `value_keys` に含まれる `--key` は次トークンを `values[key]` へ（値欠落はエラー）
- それ以外の `--flag` は `flags` へ
- `-` 始まりの未知トークンはエラー、それ以外は `positionals` へ
