## タスク概要

`cli::cmd_run` の非対話パスを実装する。worktree を解決（無ければ TASK-0003 の作成ロジックで自動作成）、
`config::resolve_llm` で LLM 決定、`claude` の場合のみ `hooks::ensure_hooks_configured` を実行、
`--resume` で `-r` を付与、`--` 以降を passthrough し、worktree dir で
`std::os::unix::process::CommandExt::exec` により起動する（正常時は戻らない）。
