## タスク概要

`src/cli/prompt.rs` に crossterm（既存依存）ベースの対話 UI を実装する。
- `select_one(title, items) -> Option<usize>`（↑↓ 移動 / Enter 決定 / Esc 中止）
- `input_line(prompt, default) -> String`
- `confirm(prompt, default_yes) -> bool`

raw mode は内部で取得・解除し、端末状態を残さない（exec 前に必ず復帰）。
alternate screen は使わず、通常スクロールバック内にインラインで描画する。
