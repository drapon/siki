## タスク概要

`cli::cmd_new` の非対話パスを実装する。プロジェクトを `discover_projects` から完全一致で解決し、
`worktree_path` を決定（既存ならエラー）、base を `--base` or `config::resolve_base_branch` で解決、
`shared_dirs` を取得して `git::create_worktree_from_ref(branch=name, Some(base), no_track=true)` を呼ぶ。
`siki.json` の `scripts.setup` があれば worktree dir で inherited-stdio 実行する。
