## タスク概要

SQLite の `sessions` テーブルに `activity TEXT`（NULL 許容）列を追加し、working（PreToolUse）受信時にツール活動文字列を永続化するための更新関数 `update_session_activity` を新設する。マイグレーションは既存の `claude_session_id` / `alert` / `alert_message` と同じ冪等 `ALTER TABLE ... ADD COLUMN` 流儀に従い、再起動時に列が既存でもエラーを握りつぶす。UI はインメモリ Registry をライブ参照するため、本列の主目的は再起動耐性と将来の MCP 連携余地である。

## 依存タスク

- **前提タスク**: なし（データ層の起点）
- **後続タスク**: [TASK-0004](TASK-0004.md)（broker 連携: activity の DB 永続）が本関数を呼び出す

```rust
// マイグレーション: activity カラムが無ければ追加（既存 claude_session_id/alert と同流儀）
// 既に列が存在する再起動時はエラーを握りつぶす（冪等）
let _ = conn.execute_batch(
    "ALTER TABLE sessions ADD COLUMN activity TEXT;",

```

### 2. 更新関数 update_session_activity の新設 🔵

**信頼性レベル**: 🔵 *interfaces.rs シグネチャ + 既存 `update_session_state` / `update_session_summary` に準拠*

**実装ファイル**: `src/db.rs`

```rust
/// sessions.activity を更新する（working 受信時に broker から呼ぶ）
pub fn update_session_activity(
    conn: &Connection,
    session_id: &str,
    activity: &str,
) -> Result<()> {
    conn.execute(
        "UPDATE sessions SET activity = ?1 WHERE session_id = ?2",
        params![activity, session_id],
    )
    .with_context(|| format!("activity の更新に失敗しました: session_id={session_id}"))?;
    Ok(())
}
```

## 単体テスト要件

テスト配置: `src/db.rs` の `#[cfg(test)] mod tests`（`cargo test` でインライン実行）

### ケースa: マイグレーションの冪等性 🔵

- **Given**: `:memory:` の Connection で `init()` を1回実行した DB
- **When**: 同じ Connection 相当に対し `init()`（または ALTER 文）を再実行する
- **Then**: `activity` 列が存在し、再実行してもエラーにならない（`PRAGMA table_info(sessions)` に activity が含まれる）
- **信頼性**: 🔵 *REQ-402*

### ケースb: activity の書き込みと取得 🔵

- **Given**: `:memory:` DB で `upsert_session`（既存）によりセッション行を作成
- **When**: `update_session_activity(&conn, session_id, "Edit: session.rs")` を呼ぶ
- **Then**: `SELECT activity FROM sessions WHERE session_id = ?` が `"Edit: session.rs"` を返す
- **信頼性**: 🔵 *REQ-102 / interfaces.rs*

## 注意事項

- SQLite は `ALTER TABLE ... ADD COLUMN` のみ可能で、既存列の型変更・削除はできない。
- `activity` は NULL 許容にし、旧バージョン作成済みの既存行は NULL のまま維持する（後方互換、UI 側は None → 「-」表示）。
- 追加インデックスは不要（UI は DB 検索せず Registry をライブ参照する）。
- マイグレーションは必ず `let _ =` で結果を握りつぶし、列既存時のエラーで `init()` を失敗させない。
