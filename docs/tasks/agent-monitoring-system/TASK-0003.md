## タスク概要

PreToolUse hook が渡す `tool_name` / `tool_input`（stdin JSON）から人間可読な1行 activity 文字列を生成する `format_activity` ヘルパを `src/hook_event.rs` に新設し、`run()` の working 経路で抽出した activity を broker 送信 payload に同梱する。改行・制御文字は1行に正規化し、想定キー欠落時は tool_name のみにフォールバックする。抽出は同期・軽量に留め、hook timeout（5s）制約を侵さない。

## 実装詳細

### 1. format_activity の新設 🔵

**信頼性レベル**: 🔵 *architecture.md 整形ルール（ヒアリング確定: description 優先）+ EDGE-001 / interfaces.rs*

**実装ファイル**: `src/hook_event.rs`

整形ルール:
- `Bash` → `description` 優先、無ければ `command`（例「Bash: テスト実行」）🔵
- `Edit`/`Write`/`MultiEdit`/`Read`/`NotebookEdit` → `file_path` のベース名（例「Edit: session.rs」）🔵
- `Task` → `Task({subagent_type}): {description}`（例「Task(Explore): 調査」）🟡
- `Grep`/`Glob` → `{tool}: {pattern}`（例「Grep: TODO」）🟡
- その他 → `tool_name` のみ（EDGE-001）🔵

```rust
/// PreToolUse payload からツール活動の1行を生成する。
pub fn format_activity(tool_name: &str, tool_input: &serde_json::Value) -> String {
    let raw = match tool_name {
        "Bash" => {
            let desc = tool_input.get("description").and_then(|v| v.as_str());
            let cmd = tool_input.get("command").and_then(|v| v.as_str());
            match desc.or(cmd) {
                Some(s) => format!("Bash: {s}"),
                None => "Bash".to_string(), // EDGE-001
            }
        }
        "Edit" | "Write" | "MultiEdit" | "Read" | "NotebookEdit" => {
            match tool_input.get("file_path").and_then(|v| v.as_str()) {
                Some(p) => format!("{tool_name}: {}", basename(p)),
                None => tool_name.to_string(), // EDGE-001
            }
        }
        "Task" => {
            let sub = tool_input.get("subagent_type").and_then(|v| v.as_str()).unwrap_or("?");
            let desc = tool_input.get("description").and_then(|v| v.as_str()).unwrap_or("");
            format!("Task({sub}): {desc}")
        }
        "Grep" | "Glob" => {
            match tool_input.get("pattern").and_then(|v| v.as_str()) {
                Some(p) => format!("{tool_name}: {p}"),
                None => tool_name.to_string(),
            }
        }
        other => other.to_string(), // EDGE-001
    };
    normalize_one_line(&raw)
}
```

### 2. normalize_one_line の新設 🟡

**信頼性レベル**: 🟡 *EDGE-002（表示崩れ防止の妥当な推測）*

**実装ファイル**: `src/hook_event.rs`

```rust
/// 改行/タブ/制御文字を空白に置換し、連続空白を1つに圧縮してトリムする。
fn normalize_one_line(s: &str) -> String {
    let replaced: String = s
        .chars()
        .map(|c| if c.is_control() { ' ' } else { c })
        .collect();
    replaced.split_whitespace().collect::<Vec<_>>().join(" ")
}
```

### 3. run() の working 経路拡張 🔵

**信頼性レベル**: 🔵 *既存 `src/hook_event.rs:38,68-73`（payload 組み立て）+ REQ-002*

**実装ファイル**: `src/hook_event.rs`

working（`state == "working"`）のときのみ `tool_name` / `tool_input` を stdin JSON から抽出し、payload に `"activity"` を追加する。working 以外は従来どおり `event` + `session_id` のみ。

```rust
let mut payload = json!({ "event": state, "session_id": session_id });
if state == "working" {
    let tool_name = input_json.get("tool_name").and_then(|v| v.as_str()).unwrap_or("");
    let tool_input = input_json.get("tool_input").cloned().unwrap_or(Value::Null);
    if !tool_name.is_empty() {
        payload["activity"] = json!(format_activity(tool_name, &tool_input));
    }
}
```

- `tool_input` / 各キー欠落時に `unwrap()` で panic しない（`and_then(as_str)` + フォールバック）。
