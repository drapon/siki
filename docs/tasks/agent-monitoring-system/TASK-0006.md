## タスク概要

`src/ui/mod.rs` に `render_agent_popup(frame, app, registry: &SessionRegistry)` を実装する。対象プロジェクト（`app.agent_popup_project_index`）配下の各 worktree について `SessionRegistry::by_worktree(project, worktree)` でライブのセッションを取得し、role / 状態バッジ / activity / summary / 経過時間（`now - last_seen`）/ alert を 1 行の `AgentRow` に整形して一覧表示する。表示は既存ポップアップと同じ `centered_rect(60, 50)` → `Clear` → `Block(Borders::ALL)` の流儀。alert または Waiting の行は赤系で強調し、長文は幅に応じて末尾 `…` で省略、スクロール窓を適用し、対象セッションが無ければ「アクティブなエージェントなし」を表示する。🔵 *dataflow.md 機能2 / interfaces.rs §5*

- 信頼性レベル: 🔵

```rust
// src/ui/mod.rs
pub fn render_agent_popup(frame: &mut Frame, app: &App, registry: &SessionRegistry) {
    let area = centered_rect(60, 50, frame.area());
    frame.render_widget(Clear, area);
    let block = Block::default()
        .title(" Agents (project) ")
        .borders(Borders::ALL);
    let inner = block.inner(area);
    frame.render_widget(block, area);
    // 行構築 → スクロール窓 → 描画（下記 2〜6）
}
```

### 2. 対象プロジェクトの worktree からセッション取得・AgentRow 構築

- 信頼性レベル: 🔵
- 出典: `dataflow.md` 機能2 ステップ3、interfaces.rs §5 `AgentRow`、`by_worktree` アクセサ
- 実装ファイル: `src/ui/mod.rs`

```rust
let project = &app.projects[app.agent_popup_project_index];
let now = std::time::Instant::now();
let mut rows: Vec<AgentRow> = Vec::new();
for wt in &project.worktrees {
    for s in registry.by_worktree(&project.name, &wt.name) {
        rows.push(AgentRow {
            project_name: s.project_name.clone(),
            worktree_name: s.worktree_name.clone(),
            role: s.role.clone(),
            state: s.state,
            activity: s.activity.clone(),
            summary: s.summary.clone(),
            elapsed_secs: now.duration_since(s.last_seen).as_secs(),
            alert: s.alert,
        });
    }
}
```

fn format_elapsed(secs: u64) -> String {
    if secs < 60 { format!("{secs}s") }
    else if secs < 3600 { format!("{}m", secs / 60) }
    else { format!("{}h", secs / 3600) }
}

// スクロール窓: 表示可能行数 = inner.height、開始 = clamp(app.agent_popup_scroll)

## UI/UX要件

- **経過時間表示**: 各行に `now - last_seen` を `12s` / `3m` / `2h` 形式で表示（REQ-005）。
- **alert/waiting の赤強調**: `is_attention` が true の行を赤系（例: `Color::Red` 前景）で強調（REQ-104）。
- **長文の省略（…）**: activity / summary が利用可能幅を超える場合は末尾を `…` で省略（EDGE-102）。
- **スクロール**: `agent_popup_scroll` を起点にスクロール窓を適用し、行数が枠を超えても閲覧可能にする（REQ-301）。
- **空表示**: 対象プロジェクトにアクティブなセッションが無いとき「アクティブなエージェントなし」を中央表示（REQ-202）。

- 経過時間・省略・赤強調の各ヘルパは TASK-0007（ダッシュボード）と**共有**する前提で実装する（重複実装しない。本タスクで定義し TASK-0007 が再利用）。
