## タスク概要

App 構造体（`src/app.rs`）に、プロジェクト別ポップアップ（`m`）と全体ダッシュボード（`M`）の表示状態を表すフィールドを追加する。`interfaces.rs` の `AgentMonitorState` で示された5フィールドを、既存の `show_*: bool` ポップアップ群と同じ流儀で App に直接追加し、初期化時に false / 0 を設定する。ロジックは含まず純粋なフィールド追加のみのため DIRECT タスクとする。🔵 *interfaces.rs §4 / 既存 show_* パターン*

## 実装詳細

### 1. App 構造体へのフィールド追加

- 信頼性レベル: 🔵
- 出典: `interfaces.rs` §4 `AgentMonitorState`、既存 `src/app.rs:252-397` の `show_*` フィールド群
- 実装ファイル: `src/app.rs`

既存の `show_help` / `show_message_popup` などと同じ位置・流儀でフィールドを追加する。別構造体化はせず App に直接持たせる（interfaces.rs の注記どおり）。

```rust
// src/app.rs : App 構造体に追加
pub struct App {
    // ... 既存フィールド ...

    /// プロジェクト別ポップアップ表示中か（REQ-003）
    pub show_agent_popup: bool,
    /// 対象プロジェクトの index（左ペイン projects の添字, REQ-106）
    pub agent_popup_project_index: usize,
    /// プロジェクト別ポップアップのスクロール位置（REQ-301）
    pub agent_popup_scroll: usize,

    /// 全体ダッシュボード表示中か（REQ-004）
    pub show_agent_dashboard: bool,
    /// 全体ダッシュボードのスクロール位置（REQ-301）
    pub agent_dashboard_scroll: usize,
}
```

### 2. 初期化での既定値設定

- 信頼性レベル: 🔵

## 単体テスト要件

本タスクは純粋なフィールド追加（ロジックなし）のため、専用の単体テストは作成しない。検証は `cargo build` の成功と、初期化値が false / 0 であることのコンパイル確認をもって行う（direct-verify）。

- Given: App を新規生成したとき
- When: 監視ビューの各フィールドを参照する
- Then: `show_agent_popup` / `show_agent_dashboard` が false、`agent_popup_project_index` / `agent_popup_scroll` / `agent_dashboard_scroll` が 0 である

（必要なら `app::tests` に上記を確認する軽量アサーションを `#[cfg(test)] mod tests` として追加してもよいが、必須ではない。`cargo test` で確認する。）

## 注意事項

- 純粋なフィールド追加でありロジックを含まないため DIRECT。TDD は不要。
- 別構造体（`AgentMonitorState`）として切り出さず、App に直接フィールドを追加する（interfaces.rs §4 の注記に従う）。
- 初期化漏れがあるとコンパイルエラーになるため、`Default`/`new` 双方が存在する場合は両方に追記する。
- イミュータビリティ方針に反しないよう、状態更新は後続タスク側で App を新しい値で更新する流儀に合わせる（本タスクでは定義のみ）。
