## タスク概要

`src/main.rs:41-56` の `resolve_claude_term_key` は、tab_index のシフト（Ctrl+W によるClaude
タブ整理）には対応済みだが、フォールバックの `find` が `key.0 == worktree_id` に絞り込まれて
おり、worktree_id 自体がシフトした場合（別worktree削除によるreindex後）は実体を見つけられ
ない。この絞り込みを撤廃し、`terminal_id` 一致のみで `claude_terms` 全体を走査するよう修正する。

## 実装詳細

### resolve_claude_term_key のフォールバック修正 🔵

**信頼性**: 🔵 *architecture.md「PTY ターミナル」・requirements.md REQ-004より*

**実装ファイル**: `src/main.rs`

```rust
fn resolve_claude_term_key(
    claude_terms: &HashMap<(app::WorktreeId, usize), terminal::TerminalEmulator>,
    worktree_id: app::WorktreeId,
    claude_idx: usize,
    terminal_id: u64,
) -> Option<(app::WorktreeId, usize)> {
    if let Some(emu) = claude_terms.get(&(worktree_id, claude_idx)) {
        if emu.id() == terminal_id {
            return Some((worktree_id, claude_idx));
        }
    }
    // 変更点: key.0 == worktree_id の絞り込みを撤廃し、
    // worktree_id 自体がシフトしていても id のみで発見できるようにする（REQ-004）
    claude_terms
        .iter()
        .find(|(_, emu)| emu.id() == terminal_id)
        .map(|(key, _)| *key)
}
```

関数直上のコメント（`main.rs:36-40`）も、worktree_id自体のシフトにも対応する旨に更新する。
