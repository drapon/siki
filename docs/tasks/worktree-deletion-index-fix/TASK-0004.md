## タスク概要

`AppEvent::ClaudeOutput`/`ClaudeComplete`/`ClaudeError`（`event.rs`）に `session_id: u64`
フィールドを追加し、`claude.rs` の送信元（`read_stdout_task` 等、`claude.rs:59,102-131`）が
`ClaudeSession.id()`（TASK-0003で追加）を各イベントに乗せて送るよう配線する。

## 依存タスク

- **前提タスク**: [TASK-0003](TASK-0003.md)（`ClaudeSession.id()` が必要）
- **後続タスク**: [TASK-0005](TASK-0005.md)

## 完了条件

- [ ] `event.rs` の `AppEvent::ClaudeOutput`/`ClaudeComplete`/`ClaudeError` に
      `session_id: u64` フィールドを追加する
- [ ] `claude.rs` の該当イベント送信箇所（`spawn`内・`read_stdout_task`内、
      `claude.rs:59,112-132`）で `id` を追加引数として受け取り、`session_id` に設定する
- [ ] 既存テスト（`claude.rs:457-590`）を新しいフィールドに合わせて更新する
- [ ] `main.rs` 側の対応するイベントパターンマッチ（`main.rs:654,684,710`）が
      `session_id` を無視せずコンパイルが通る状態にする（配線本体はTASK-0005で実施）
- [ ] `cargo build`/`cargo test` が通る

## 実装詳細

### AppEvent フィールド追加 🔵

**信頼性**: 🔵 *architecture.md「event.rsの変更」より*

**実装ファイル**: `src/event.rs`

```rust
AppEvent::ClaudeOutput {
    worktree_id: WorktreeId,
    session_id: u64,           // 新規: REQ-006 の id 解決に使用
    event: ClaudeStreamEvent,
},
AppEvent::ClaudeComplete {
    worktree_id: WorktreeId,
    session_id: u64,           // 新規
},
AppEvent::ClaudeError {
    worktree_id: WorktreeId,
    session_id: u64,           // 新規
    error: String,
},
```

### claude.rs 送信元の配線 🔵

**信頼性**: 🔵 *コード調査 (`claude.rs:59,102-131`) より*

**実装ファイル**: `src/claude.rs`

- `read_stdout_task`（`claude.rs:102`）の引数に `session_id: u64` を追加し、
  `spawn`（`claude.rs:59`）呼び出し時に `id`（TASK-0003で採番した値）を渡す
- `ClaudeError`/`ClaudeOutput`/`ClaudeComplete` 送信箇所（`claude.rs:112-131`）すべてに
  `session_id` を追加する
